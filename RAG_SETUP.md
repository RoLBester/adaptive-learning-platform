# RAG-Enhanced Recommendations Setup Guide

## Overview

This document explains the new RAG (Retrieval-Augmented Generation) recommendation system that provides intelligent, semantic-based study material suggestions.

## What is RAG?

RAG (Retrieval-Augmented Generation) combines semantic search with personalized recommendations. Instead of simple keyword matching, it:

1. **Understands Context**: Analyzes user performance to identify specific learning gaps
2. **Semantic Matching**: Finds resources based on meaning, not just exact words
3. **Intelligent Ranking**: Returns results ranked by relevance (similarity scores)

---

## Architecture

```
User takes quiz → Performance analysis
                        ↓
            Generate semantic query
         "beginner algebra basics linear equations"
                        ↓
            Convert to embedding vector (384-dim)
                        ↓
         Search vector database (ChromaDB)
                        ↓
            Return top 5 most relevant resources
                   (ranked by similarity)
```

---

## Technology Stack

### New Dependencies

- **ChromaDB** (v0.4.22): Local vector database
  - Stores embeddings persistently
  - Fast cosine similarity search
  - No API keys or cloud costs

- **Sentence-Transformers** (v2.3.1): Embedding generation
  - Model: `all-MiniLM-L6-v2`
  - 384-dimensional vectors
  - Optimized for semantic similarity

## Setup Instructions

### 1. Install Dependencies

```bash
cd backend
source venv/bin/activate
pip install chromadb==0.4.22 sentence-transformers==2.3.1
```

Or install from requirements.txt:
```bash
pip install -r ../requirements.txt
```

### 2. Start the Backend

```bash
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

The vector store will initialize automatically on first run.

### 3. Seed Resources (If Not Done)

Visit http://127.0.0.1:8000/docs and run:
```
POST /api/seed-resources/
```

This populates the MongoDB Resources collection with sample data.

### 4. Embed Resources into Vector Database

**IMPORTANT**: This is a one-time setup step.

Visit http://127.0.0.1:8000/docs and run:
```
POST /api/embed-resources/
Body: { "clear_existing": false }
```

**What this does**:
- Fetches all resources from MongoDB
- Generates 384-dimensional embedding vectors
- Stores them in ChromaDB (backend/chroma_db/)
- Takes ~30-60 seconds for 50-100 resources

**Expected Response**:
```json
{
  "message": "Successfully embedded 7 resources",
  "resources_embedded": 7,
  "collection_size": 7
}
```

### 5. Start the Frontend

```bash
cd frontend
npm start
```

Opens at http://localhost:3000

## Using the RAG System

### In the UI

1. Navigate to **Learning Path** page
2. You'll see a toggle: **"Use RAG (Semantic Search)"**
3. Toggle ON to use RAG, OFF for baseline system
4. Enter user ID (e.g., "user123")
5. Click "Get Recommendations"

### Compare RAG vs Baseline

- **Baseline** (Toggle OFF): Simple topic matching
  - Returns all resources for weak topics
  - No ranking or relevance scoring

- **RAG** (Toggle ON): Semantic search
  - Generates intelligent query based on mistakes
  - Returns top 5 most relevant resources
  - Shows similarity scores (0-100% match)
  - Labeled as "Highly Relevant", "Relevant", etc.

## How It Works (Technical Deep Dive)

### 1. Embedding Generation

```python
# When you run /api/embed-resources/
text = f"{title}. {description}. Topic: {topic}"
# Example: "Basic Algebra Guide. Algebra fundamentals. Topic: Algebra"

embedding = model.encode(text)
# Result: [0.123, -0.456, 0.789, ...] (384 numbers)
```

### 2. User Query Generation

```python
# User fails Algebra quiz
weak_topics = ["Algebra"]
overall_score = 40  # Low score → beginner level

query = f"beginner Algebra fundamentals basics introduction tutorial"
```

### 3. Semantic Search

```python
# Convert query to embedding
query_embedding = model.encode(query)

# Find similar vectors using cosine similarity
results = vector_db.search(query_embedding, top_k=5)

# Results ranked by similarity:
# 0.892 - "Basic Algebra Guide"
# 0.8 41 - "Algebra Practice Problems"
# 0.765 - "Khan Academy: Algebra Basics"
```

### 4. Why Semantic Search is Better

**Example Query**: "struggling with derivatives"

- **Keyword Matching** (Baseline):
  - Searches for exact word "derivatives"
  - Might miss "Calculus differentiation basics"

- **Semantic Search** (RAG):
  - Understands "derivatives" → calculus → differentiation
  - Finds all related resources even without exact words
  - Ranks by how well they match the concept

## Troubleshooting

### Issue: "Vector DB Status: empty"

**Solution**: Run `/api/embed-resources/` endpoint first

### Issue: "No module named 'chromadb'"

**Solution**:
```bash
pip install chromadb==0.4.22 sentence-transformers==2.3.1
```

### Issue: Embedding takes too long

**Cause**: First-time model download (80MB)
**Solution**: Wait 2-3 minutes for sentence-transformers to download

### Issue: "Failed to initialize ChromaDB"

**Solution**: Check `backend/chroma_db/` has write permissions
```bash
chmod -R 755 backend/chroma_db/
```
